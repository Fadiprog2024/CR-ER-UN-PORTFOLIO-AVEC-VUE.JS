# Créer un portfolio avec Vue.js

## Présentation du projet

Ce projet consiste à créer un portfolio personnel en utilisant Vue.js.

L'objectif est de présenter mes compétences, mes réalisations et mes projets à travers un site web moderne et responsive.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Vue.js
- Git et GitHub

## Fonctionnalités prévues

- Page d'accueil
- Présentation personnelle
- Présentation des compétences
- Présentation des projets
- Formulaire de contact
- Interface responsive

## Installation

Les instructions d'installation et de lancement du projet seront ajoutées au cours du développement.
